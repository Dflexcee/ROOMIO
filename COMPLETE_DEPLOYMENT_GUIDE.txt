## STEP 6: CREATE .htaccess FILE (If not exist)

1. Navigate to: public_html/
2. Check if .htaccess exists
3. If NOT, create new file: .htaccess
4. Add this content:

---
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  
  # Don't rewrite files or directories
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  
  # Don't rewrite API requests
  RewriteCond %{REQUEST_URI} !^/php-api/
  
  # Rewrite everything else to index.html
  RewriteRule ^ index.html [L]
</IfModule>

Options -Indexes

<IfModule mod_headers.c>
  Header set X-Content-Type-Options "nosniff"
  Header set X-Frame-Options "SAMEORIGIN"
  Header set X-XSS-Protection "1; mode=block"
</IfModule>
---

## 🔧 TROUBLESHOOTING

ERROR: "Failed to fetch" or "Database connection failed"
FIX: Check public_html/php-api/.env has correct database password

ERROR: "404 Not Found" on API calls
FIX: Check php-api/public/ folder exists with all PHP files

ERROR: "404 on routes" (e.g., /dashboard shows 404)
FIX: Check .htaccess file exists in public_html/

ERROR: "CORS error"
FIX: Check CORS_ORIGINS in .env includes your domain

ERROR: "Upload failed"
FIX: Check uploads/ folder permissions (should be 755 or 777)
