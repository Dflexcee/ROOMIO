# ============================================================================
#                    WHY ONLY 3 FILES?
# ============================================================================

The codebase follows best practices:

1. **Centralized Configuration**
   - All config values stored in .env file
   - Config.php loads .env and provides defaults
   - All files use Config::get() to read values

2. **URL Helper Functions**
   - UrlHelper.php provides URL generation functions
   - All files use UrlHelper:: methods
   - No hardcoded URLs anywhere in the code

3. **Pre-built Frontend**
   - Frontend is built with production URLs baked in
   - No runtime URL configuration needed
   - dist/ files ready to upload
