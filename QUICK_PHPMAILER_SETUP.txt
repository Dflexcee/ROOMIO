📁 WHERE TO PUT PHPMAILER:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Put your PHPMailer folder here:

C:\xampp\htdocs\roomio\php-api\vendor\phpmailer\phpmailer\

The folder structure should be:

roomio/
└── php-api/
    └── vendor/                    ← Create this folder
        └── phpmailer/             ← Create this folder
            └── phpmailer/         ← Put PHPMailer here
                └── src/           ← Must have src folder
                    ├── PHPMailer.php      ← Important!
                    ├── SMTP.php           ← Important!
                    └── Exception.php      ← Important!


🔧 STEP-BY-STEP:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open File Explorer

2. Navigate to: C:\xampp\htdocs\roomio\php-api\

3. Create these folders (if they don't exist):
   - vendor
   - vendor\phpmailer
   - vendor\phpmailer\phpmailer

4. Copy your PHPMailer folder contents into:
   C:\xampp\htdocs\roomio\php-api\vendor\phpmailer\phpmailer\

5. Verify these files exist:
   - C:\xampp\htdocs\roomio\php-api\vendor\phpmailer\phpmailer\src\PHPMailer.php
   - C:\xampp\htdocs\roomio\php-api\vendor\phpmailer\phpmailer\src\SMTP.php
   - C:\xampp\htdocs\roomio\php-api\vendor\phpmailer\phpmailer\src\Exception.php


✅ TEST INSTALLATION:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

http://localhost/roomio/php-api/public/test-email.php

You should see:
{
  "success": true,
  "message": "PHPMailer is installed correctly!"
}


📧 CONFIGURE SMTP:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Visit: http://localhost:5173/admin/smtp-settings

2. Enter your email settings:

   For Gmail:
   ┌─────────────────────────────────────────┐
   │ SMTP Host: smtp.gmail.com               │
   │ SMTP Port: 587                          │
   │ Username: your-email@gmail.com          │
   │ Password: (app password)                │
   │ From Email: your-email@gmail.com        │
   │ From Name: Roomio                       │
   │ Encryption: tls                         │
   └─────────────────────────────────────────┘

3. Click "Save"


🔒 GMAIL APP PASSWORD:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://myaccount.google.com/security

2. Enable "2-Step Verification"

3. Go to: https://myaccount.google.com/apppasswords

4. Create app password for "Mail"

5. Copy the 16-character password

6. Use this in SMTP Settings (NOT your regular Gmail password)


💡 IMPORTANT NOTES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ If PHPMailer is NOT installed:
  → System automatically uses PHP mail() function
  → Still fetches SMTP settings from database
  → Emails still work!

✓ If PHPMailer fails:
  → System automatically tries PHP mail() as backup
  → Emails still work!

✓ Double Protection:
  → Method 1: PHPMailer (more reliable, better features)
  → Method 2: PHP mail() (always available as backup)


🎯 WHAT HAPPENS WITHOUT PHPMAILER:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Email will still work using PHP's built-in mail() function!

The system will:
✓ Fetch SMTP settings from database
✓ Use those settings for From/Reply-To headers
✓ Send emails using PHP mail()
✓ Log a note that PHPMailer wasn't found
